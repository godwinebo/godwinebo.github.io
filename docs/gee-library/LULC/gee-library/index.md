# Google Earth Engine Code Library

This library presents geospatial analysis workflows developed with Google Earth Engine.

## Featured projects

- [2025 Land Use/Land Cover Classification — Adansi South District](lulc-2025-adansi-south.md): Landsat 8 and 9 imagery, Random Forest classification, six land-cover classes, and mapped area summaries.

Each project page provides an overview, methods, outputs, example map, and source code.
