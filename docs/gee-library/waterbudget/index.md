# Google Earth Engine Code Library

Explore reproducible geospatial workflows developed with Google Earth Engine (GEE) for environmental monitoring, hydrological assessment, climate resilience, and sustainable development.

This library documents the objectives, datasets, methods, assumptions, and outputs of each workflow.

## Featured workflow

### Water Budget and Storage-Change Analysis

Estimate basin-scale precipitation, evapotranspiration, runoff, and changes in terrestrial water storage using satellite-derived and model-based datasets.

**Methods:** Water-balance accounting, basin averaging, monthly and annual aggregation, climatology, time-series visualization, and geospatial exports.

**Platform:** Google Earth Engine Code Editor (JavaScript)

[Explore the Water Budget workflow](water-budget.md){ .md-button .md-button--primary }

## How to use this library

1. Read the scientific objective and dataset descriptions.
2. Review the assumptions and limitations.
3. Copy the JavaScript source into the [Google Earth Engine Code Editor](https://code.earthengine.google.com/).
4. Configure the study area, analysis period, and data options.
5. Run the script, inspect the outputs, and initiate any required export tasks.
