# Google Earth Engine Code Library

This section presents geospatial analysis workflows developed with Google Earth Engine (GEE).

## Featured analysis

- [RUSLE Soil Loss and Erosion Risk Mapping](rusle-soil-loss.md) — estimates potential annual soil loss using the Revised Universal Soil Loss Equation (RUSLE), maps erosion-severity classes, and exports raster outputs.

Each project page includes the objective, workflow, datasets, key settings, example output, and JavaScript source code.

> **Research note:** Model outputs are estimates. Review the assumptions, input data, spatial resolution, and local calibration requirements before using results for decisions.
